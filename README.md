Ecco il progetto del Atelier- studio di Architettura:
Struttura HTML5 semantica: Utilizzo di tag semantici (<header>, <main>, <section>, <article>, <footer>), 
griglia Bootstrap responsive e componenti nativi (Navbar sticky con menu collassabile sotto i 768px,
card per i servizi e form di contatto validato).   

Personalizzazione SCSS: Definizione delle variabili di brand basate sui codici HSL forniti,
override delle classi Bootstrap (.btn-primary, .bg-primary, ecc.) e creazione di un mixin dedicato 
(@mixin card-elevata) per le transizioni e le ombre delle card al passaggio del mouse.   

Interattività JavaScript: Gestione della chiusura automatica del menu mobile al click sui link di navigazione
e validazione dei campi del form di contatto (controllo della presenza della @ nell'email e lunghezza minima del messaggio) 
con messaggi di feedback dinamici.
